# Claims and the gates that enforce them

Every substantive claim the README makes, and the check that would fail if it
stopped being true. Nothing on this page is enforced by this page: each row
names a script or a test that runs in `./scripts/preflight.sh`, and
`scripts/ci/claims-coherence.sh` refuses to pass if a row names something that
does not exist.

The point is not that the claims are documented. It is that none of them is an
assertion a reader has to take on trust — every one is a thing the build already
proves on every change, and this table is the index.

## The codec

| Claim | Enforced by |
| --- | --- |
| Progressive 8-bit 4:2:0 `C420jpeg` Y4M, even dimensions from 64×64 to 4096×2304 | `crates/kf-bitstream/tests/normative_limits.rs` drives the real constructor with the bounds `spec/v1/constants.toml` declares and requires everything outside them to be refused |
| Quadtree partition from 64×64 down to 8×8, chosen by closed-loop rate–distortion search | `scripts/ci/intra-gate.sh`, and `crates/kf-tools/tests/ablation_quality.rs` measures what the quadtree is worth |
| Eight intra modes; P-frames from LAST and GOLDEN with quarter-pixel six-tap motion compensation, median motion-vector prediction, and reference-selecting skip | `scripts/ci/inter-gate.sh` covers every P-frame branch; the six filter taps are frozen in `spec/v1/mc.toml` and replayed by `spec/oracle.py` |
| Literal 4/8/16/32 integer transforms, flat quantization across the full 64-step quantizer range | `scripts/ci/transform-gate.sh` replays 24 literal vectors at every size and saturates the extremes |
| Deblocking before a frame becomes a reference | `scripts/ci/deblock-gate.sh`, including `trap_loopfilter_ref_identity` |
| Each declared filter-activity skip rule has a vector that fails if the rule is dropped | `spec/check_assets.py` requires every declared skip condition to name a vector that leaves its samples untouched, and both decoders replay all seven through `scripts/ci/deblock-gate.sh`. Two of the three rules previously had none: removing either from both decoders left the deblock gate green and showed up only as an unexplained conformance hash drift |
| Sync-marked packets with independent header and payload CRC32C, byte-by-byte resynchronization after damage, and a frame installed into the reference state only on complete success | `scripts/ci/bitstream-gate.sh` covers the header, checksum, and resynchronization rules; `scripts/ci/error-matrix-gate.sh` covers what happens when they fire |
| Every syntax element round-trips, and the partition tree, prediction branches, and coefficient coding mean what the tables say | `scripts/ci/syntax-gate.sh` |
| Adaptive binary range coder over a closed set of 144 contexts | `scripts/ci/range-gate.sh` and `crates/kf-range/tests/normative_limits.rs`, which check the probability clamps, the adaptation rate, the context count, and the finalization tail against the frozen constants |
| Modeled-entropy costs the encoder reuses for its own decisions | `scripts/ci/entropy-gate.sh` |
| The declared motion-vector predictor candidates are the neighbours both decoders read, in the order and with the fallback the declaration names | `crates/kf-predict/tests/declared_predictor.rs` and the `declared_predictor` module in `crates/kf-ref/src/motion.rs`, each reading `spec/v1/mc.toml` through its own parser. ## Verification

| Claim | Enforced by |
| --- | --- |
| Which edges the loop filter touches is declared, and read by both filters and by the document | `crates/kf-predict/src/deblock.rs`: `the_shortest_filtered_edge_is_the_declared_one` requires a block at the declared minimum to contribute edges and one below it to contribute none. `deblock.toml` states the minimum once; it had been written three times in each filter — the luma collection, twice the minimum in the chroma derivation, and the minimum again after halving — and once more as the English word "eight" in the generated document, which no search for the number could find |
| Every normative limit the encoder and the syntax layer enforce is the declared one, derived where it is a derivation | `crates/kf-bitstream/tests/normative_limits.rs` writes a motion-vector difference at `(mv_fullpel_max - mv_fullpel_min) << mv_fractional_bits` and one past it — the syntax layer carried that arithmetic's answer as a literal, so the three declarations governed nothing that codes a vector; `crates/kf-enc/tests/rate.rs` drives both places the encoder validates a quantizer with the declared ceiling |
| Every normative limit both decoders enforce is the one the specification declares | `crates/kf-bitstream/tests/normative_limits.rs` drives the production constructors with the declared picture bounds, quantizer range, payload cap, and initial read; `crates/kf-ref/src/scan.rs` reads the same declarations through this decoder's own parser — picture bounds, sample format, quantizer range, superblock side, payload bounds, and coefficient cap — and drives each boundary, where no committed vector reaches |
| Every pinned regression stream is explained by a catalogue entry, and every entry pins a stream | `scripts/collect-cutting-room.mjs` refuses to build the site if an entry names a stream that is not there or `conformance/crashes/` holds one no entry names |
| Two decoders, written independently, agreeing bit-exactly | `scripts/ci/reference-gate.sh` and `scripts/ci/conformance-gate.sh`, which compares the committed suite against a fresh generation in both directions — a vector that changed or vanished, and a vector present that nothing authors, since a file left behind by a rename is decoded by the gates that glob these directories and described by no manifest; `scripts/ci/forbidden-grep.sh` fails the build if `kf-ref` ever imports a production codec crate or declares a dependency beyond `kf-frame` and `kf-spec` |
| Conformance coverage stated as a measurement: every reachable syntax element and context slot, with at least one stream per element the encoder did not author | `scripts/ci/coverage-gate.sh`, which instruments both decoders and counts |
| Bit-exactness on natural video, not only synthetic sources | `scripts/ci/corpus-gate.sh`, every pinned clip at five quantizers in both decoders and the encoder's closed loop |
| Every field the corpus manifest pins is checked against the clip that arrives | `scripts/fetch-corpus.sh` reads the address, checksum, dimensions, and frame count from `corpus/manifest.toml` through `scripts/corpus-manifest.sh` and refuses a clip that disagrees with any of them. `scripts/ci/corpus-gate.sh`, `scripts/ci/rate-gate.sh`, and the rate–distortion campaign take their clip list from the same place — the campaign through `pinned_clips` in `crates/kf-tools/src/corpus.rs` — so a clip the corpus gains is measured rather than merely declared, and a manifest that parses to nothing is a failure rather than a loop that runs zero times |
| The byte offset an error carries names the field that was wrong, in both decoders | `crates/kf-bitstream/tests/offset_probe.rs` and `crates/kf-tools/tests/error_matrix.rs`: each spoils one sequence-header field and requires both decoders to refuse it at the offset `spec/v1/fields.toml` declares for that field, reading the layout rather than restating it. Six fields were reported at another field's byte — height at the width's, and in the reference decoder depth at the chroma's, both frame rates and the keyframe interval at byte twelve, the sequence flags at the golden interval's, and the packet's reserved field at the quantizer's. Nothing compared them: the error matrix compares frame statuses and the campaign compares pictures, while the one test that read an offset printed it and asserted nothing |
| Damage detected, contained, and never allowed into later prediction | `scripts/ci/error-matrix-gate.sh`, thirteen named traps in both decoders plus a single-byte wound sweep |
| Decoder campaigns with zero panics or hangs | `scripts/ci/fuzz-gate.sh` runs a real campaign at the declared preflight budget on every change, and `crates/kf-fuzz/tests/campaign.rs` holds both compiled budgets to the declaration. The larger nightly budget is a workflow no hosted pipeline has run; what has been run at it is recorded in [writeup 5](WRITEUPS.md#5-fuzzing-my-own-decoder) |
| Any frame seekable to the same image linear decoding produces | `scripts/ci/seek-gate.sh` |
| Every decision that constrains the format is recorded, indexed, and reachable by its number | `scripts/check-doc-coherence.mjs` requires the decision log in `docs/CODEC-SPEC.md` to be a gapless numbered sequence with every row present, so a record cannot be dropped or added out of order without the gate failing |
| The specification and the implementation cannot drift apart silently | `scripts/ci/spec-check.sh`: the normative document is regenerated and diffed, `spec/check_assets.py` re-derives the tables, and `spec/mutation_check.py` mutates each asset and requires a rejection |
| No number or table the specification declares is decoration: every numeric scalar and every declared array in the frozen assets is reachable from something that runs | `scripts/ci/declared-scalar-use.sh`, which fails on any declared scalar or table no crate, specification script, CI script, or interface source names — the check that would have caught a coefficient-coding parameter table describing a scheme this codec never implemented. The generated document deliberately does not count as a reader — everything appears there, which is what makes it a document rather than a check — and the gate carries no exemption list, because a number nobody can justify checking is a number the specification should not declare |
| The header offsets, checksum spans, and flag masks a decoder trusts before it trusts anything else are derived from the declared field layout, not asserted beside it | `spec/check_assets.py` rebuilds both header layouts from their own field lists and requires every offset, length, and mask to fall out of them — including that the packet checksum begins after the sync marker, since resynchronization scans for that marker and cannot have it under the checksum |
| Where two assets state the same fact, they are made to agree | `spec/check_assets.py` reconciles the constant table against the component assets that restate it — the scene-cut bounds, the full-pixel motion range, the quantizer range, the coefficient cap, and the probability clamps — so an edit to either copy fails rather than leaving the normative document contradicting itself |
| The coefficient magnitude cap both decoders enforce is the one the specification declares | `crates/kf-transform/tests/stage_widths.rs`: `trap_coefficient_level_cap` reads `coefficient_abs_max` from `spec/v1/quant.toml` and drives the quantizer and the dequantizer at the cap and one past it in both signs; the production quantizer, the syntax layer, and the reference decoder each read the same declaration through their own parser rather than restating it |
| Every value the decoder-normative document states is one it read from the asset that declares it | `scripts/ci/declared-scalar-use.sh` asks `spec/generate_docs.py --template` for the document's own source text and fails on any declared value typed into it as a literal. The document restated most of what it described — the reconstruction clamp, the angular scale and its four angles, the interpolation taps, the context count, both header layouts, the quantizer range — so editing a frozen asset moved both decoders and left the document stating the old number, with the regenerated file and every gate still green. It is the artifact a second implementer builds from, which makes it the worst place in the tree for a stale value |
| The decoder-normative document states the limits a second decoder has to enforce, not only the ones this one does | `crates/kf-bitstream/tests/normative_limits.rs` drives the motion-vector difference bound the document now publishes, and `spec/check_assets.py` derives the angular angles the document now names. The document had described eight intra modes without saying what any of the four angular ones projects at, and had never stated the motion-vector range at all — a reader implementing from it would have accepted vectors this codec rejects |
| The frozen probe schema restates no declaration it is not reconciled with | `spec/check_assets.py` compares every bound the schema freezes against the asset that declares it — picture bounds, quantizer range, payload bounds, superblock side, coding-block sizes, sample depth, bitstream version, chroma siting, intra mode names, reference names, and the context id ceiling — and `spec/mutation_check.py` widens the schema's largest picture and requires a rejection. Only `probe_version` had ever been compared to anything, so `scripts/ci/probe-gate.sh` validated reports against a second copy of the same guess |
| A prose declaration that carries a number another declaration states is reconciled with it | `spec/check_assets.py`: the neighbour substitution rule names the declared unavailable fallback, the precision and motion-vector units name the declared phase denominator, and the rate bucket's declared update formula shifts by the declared fractional width. Each was a second spelling of a value the assets already declare, in a string no scan of numbers could see — the same defect as the minimum edge length written as the English word "eight". This narrows the prose scope rather than closing it, and the count of what stays outside is still printed |
| The help a tool prints is the behaviour the tool has | `crates/kf-tools/tests/encoder_tool.rs`: `the_help_text_states_the_declared_defaults_and_nothing_else` requires `kfenc`'s usage text to state the declared quantizer range and both declared interval defaults, and to contain no other number but the one default no asset declares. The text used to spell all four out while the parser fifteen lines below read two of them from the specification |
| The bounds the projection room's source reader enforces are the declared ones | `scripts/ci/interface-coherence.mjs` compares `SOURCE_LIMITS` in `inspector/src/source.ts` and the quantizer ceiling in `inspector/src/render.ts` against `spec/v1/constants.toml`, and `inspector/tests/encoding.spec.ts` derives its refusal cases from the same table rather than restating them. The page carried the picture bounds and the chroma siting as literals whose comment said they were the codec's own — true, and true because two people typed the same numbers |
| The declared-value gate names the scope it does not cover, and counts it | `scripts/ci/declared-scalar-use.sh` scans numbers and tables, and says so: the assets also declare prose — an order, a distortion measure, an accumulator width — which a reader checks by reading and which the vectors that replay the arithmetic actually hold. The count of prose declarations, and of the single-digit declarations the document scan skips because the document's own ratios and array arithmetic collide with them, is printed on every run, so each limit is a number rather than an assumption |
| Every declared scalar is load-bearing, not decorative normative text — the transform stage shifts and reconstruction clamp, the intra angular scale, and the interpolation taps, filter scale, rounding biases, phase denominators, and edge extension | `crates/kf-transform/tests/declared_shifts.rs` evaluates the shift formulas the asset declares and compares them to the shifts the code uses; for transforms, motion compensation, and intra prediction the production path, `kf-ref`, and `spec/check_assets.py` each read the same declarations through their own parser rather than restating the numbers, so no two of the three agree except by agreeing with the specification. The reference decoder's angular blend was the last place this was not true: it read the declared scale twice and then took its complement against a literal `32`. Scalars the committed vectors cannot police — a rounding bias that rounds the same way either side, a phase denominator no committed motion vector is large enough to distinguish — are pinned by the relations that hold between them in `spec/check_assets.py`, and `spec/mutation_check.py` rejects a change to any of them |

## Integer-only signal path

| Claim | Enforced by |
| --- | --- |
| No public function in a codec crate is unreachable decoration | `scripts/ci/forbidden-grep.sh` scans the perimeter and `cargo doc` publishes what survives; four accessors were reachable from nothing — not production code, not a test, not the interface, not a script — while carrying `#[must_use]` and a doc comment that made them read as contract. A specification value nobody can justify checking is one the specification should not declare, and the same is true of an entry point nobody can justify calling |
| No Rust dependency but the workspace's own crates | `scripts/ci/dependency-closure.sh` requires every package `Cargo.lock` resolves to be a member of this workspace, and the member list to be exactly the crates on disk — a crate directory no member line names is scanned by the forbidden-API gate and compiled by nothing |
| No floating point, unordered iteration, ambient clocks, filesystem, or threads in any codec crate, the WebAssembly module included | `scripts/ci/forbidden-grep.sh`, fail-closed: every crate under `crates/` is scanned unless it is named as a host crate, so a new codec crate is covered the day it appears. Two crates are named — the tools and the fuzz harness — and both allow `disallowed_types` and mean it. `kf-wasm` is scanned like any other: the addresses it hands a host are exposed and recovered explicitly rather than cast, so the artifact a visitor's browser runs is inside the perimeter rather than beside it |
| Floating point confined to the tools and the interface | the same scan, plus `disallowed_types = "deny"` in the workspace lint table |
| Every numeric cast in a codec crate either cannot lose anything or carries the rule that says what it discards | the same scan reads the comment block directly above each `as` cast and fails unless it begins `cast:`. Four survive the rule, and the load-bearing one is the range encoder's delayed carry in `crates/kf-range/src/encoder.rs`, where `try_from` would reject exactly the case the carry logic exists to handle. A cast is invisible to both the lint build and the checked-arithmetic release profile, because truncation is not an overflow — it is an answer |
| Release builds stop on an integer overflow rather than wrapping | `crates/kf-fuzz/tests/campaign.rs` asserts it, and the campaign binary asks `overflow_is_checked()` of itself before its first iteration and refuses to report a clean run from a build that would wrap. The artifact proves the setting, because `cargo test --release` and `cargo run --release` select different profiles and a test elsewhere would be asking the wrong build |
